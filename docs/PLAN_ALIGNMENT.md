## What “working” currently means

An authorized upload can progress without further processing buttons through
registration, extraction/OCR, evidence-linked proposals, catalog checks, layout,
native-PDF QA and a downloadable review issue containing a real editable Excel
workbook. Browser closure does not delete work. Corrections generate new drafts
without overwriting accepted edits or old artifacts.

The supplied reviewed PDF is used in that actual software path. It generates
unreviewed inventory and graphical candidates, not a fabricated exact engineering
model. Unsupported interpretations appear in the review queue. Original-plan
48/49 counts and authoritative manufacturer values must not be substituted with
results from this reviewed input or synthetic fixtures.

Direct CAESAR II import is a later explicit user addition. The application keeps
that gate blocked until its version/import contract and round trip are qualified.
These limits do not prevent PDF review or editable workbook export.
